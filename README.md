# 집 도우미 (옛 이름: 살림 알리미)

냉장고 식재료와 생활용품(화장지·치약·샴푸·세제…)을 언제 샀는지 기억하고,
다 떨어지거나 상하기 전에 **매일 정한 시간에 핸드폰 알림**으로 알려주는 안드로이드 앱.

## 기능
- 🛒 **샀어요**: "오이 5개 망가 5개 마멍 5개 샀어"처럼 말하면 자동으로 정리 (망가=망고, 마멍=파파야)
- 🍳 **해먹었어요**: "카레랑 오이무침 해먹었어" → 음식별 평균 재료를 가족 수에 맞춰 계산해서 재고에서 뺌
- 🧻 **생활용품**: 가족 수·화장실 수로 하루 사용량 계산 → 다시 살 날 알림
- 🧊❄️🧺 **보관 장소**: 냉장·냉동·실온 따로 (냉동은 오래 보관)
- 🛍️ **장보기 목록**: 떨어져 가는 것 자동으로 모으고 왓츠앱으로 보내기
- 🔔 **알림**: 앱을 안 열어도 매일 아침(시간 설정 가능) 알림, 핸드폰을 껐다 켜도 유지
- 🎤 말로 입력 (한국어)

## 핸드폰에 설치하기
1. 코드를 올리면 GitHub가 자동으로 APK를 만듭니다 (약 3~5분).
2. 저장소의 **Releases** 에서 가장 최신 `SalimAlimi-번호.apk` (집 도우미) 를 핸드폰으로 내려받습니다.
3. 파일을 열고 "출처를 알 수 없는 앱 설치"를 허용하면 설치됩니다.
4. 처음 열 때 **알림 허용**을 눌러 주세요.

## 구조
- `app/src/main/assets/index.html` — 화면 전체 (재고 계산, 음식별 재료표 `RECIPES`, 보관 기간표 `SHELF`, 생활용품 사용량표 `HOME`)
- `MainActivity.kt` — 화면을 띄우고 저장·음성 입력·공유를 연결
- `Notifier.kt` — 매일 정한 시간에 알림 (AlarmManager), 재부팅 후 다시 맞춤
